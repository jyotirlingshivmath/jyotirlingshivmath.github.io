Jyotirling Shivmath — YouTube Shorts Upload Planner

यह Desktop Upload Planner है। यह Shorts Creator से अलग है और वीडियो नहीं बनाता। यह GitHub Release में मौजूद individual Short ZIP packages की सूची दिखाता है। चुने हुए Shorts की तारीख/समय Queue में सेव होंगे। GitHub Actions Scheduler उन्हें YouTube पर upload करेगा; भविष्य का समय होने पर YouTube उन्हें उसी समय Public करेगा।

1. GitHub कनेक्शन

Token को इस repository lettermanagementorthosgpgi-coder/jyotirlingshivmathlive के लिए कम-से-कम Contents: Read and write तथा Metadata: Read अनुमति चाहिए। Token केवल इसी browser से GitHub API को भेजा जाता है; किसी अन्य server को नहीं।

2. Individual Short Packages

अभी कोई Release लोड नहीं हुई।

पहले Release लोड करें, फिर Load Short Packages दबाएँ।

3. YouTube Upload Queue

हर चुने हुए Short के लिए तारीख और समय भरें। समय आपके Desktop के local time zone के अनुसार लिया जाएगा। Scheduler Queue में आने के बाद upload शुरू करेगा; इसलिए भविष्य की तारीख चुनने पर भी वीडियो पहले YouTube पर Private upload होगा और निर्धारित समय पर Public होगा।
