Facebook credentials are stored in GitHub Secrets

Dashboard में Facebook token नहीं रखा जाता। Repository Settings → Secrets and variables → Actions में ये Secrets जोड़ने होंगे:

  • FACEBOOK_PAGE_ACCESS_TOKEN — आपका Page Access Token
  • FACEBOOK_PAGE_ID — 220330131330351
  • SOURCE_REPOSITORY_TOKEN — Live repository पर Contents: Read वाला token (उसी Fine-grained token का उपयोग कर सकते हैं)

Queue में Short तभी जाएगा जब आप “Approve & Add to Facebook Queue” दबाएँगे। Scheduler हर 5 मिनट पर Queue देखेगा। यह स्क्रीन स्वयं कोई वीडियो प्रकाशित नहीं करती।
